# Roadmap

## v0.7.0 — Public Alpha

Completed stages 1–10: App Server integration, model routing, durable limit waiting,
mission queue, security and recovery, native desktop and overlay, Model Policy,
and Limit & Credit Manager 2.0. Source distribution only.

## In development

- Stage 11: Graceful Pause & Resume. Not included in this public snapshot; hard
  interruption has not been confirmed by successful real integration testing.

## Planned

- Stage 12: Visual Revolution.
- Stage 13: Intelligent Router 2.0.
- Stage 14: Project Orchestration.
- Further security review, compatibility testing and preparation for a mature release.

No delivery dates or guarantees are implied. Other providers, monetization and cloud
infrastructure are outside the scope of this alpha.
