# Contributing

This is an early Windows-focused alpha. Open an issue describing a reproducible problem
or proposed change before a large contribution. Use neutral paths and synthetic data;
never attach account tokens, auth files, private prompts, databases or session identifiers.

Create a focused branch, install `.[desktop,dev]` in Python 3.12+, and run the full offline
suite from [TESTING.md](docs/TESTING.md). Include reproduction steps, relevant tests and
security implications in the pull request. Keep recovery, approval and credit gates intact.
Do not weaken tests to make CI pass. Real account inference is not a contribution check.

Submit only code and assets you have the right to contribute under the project's license.
Preserve third-party notices. Use your actual Git identity. Do not add AI agents as Git
authors, committers, co-authors or contributor credits. Be respectful and report security
issues through [SECURITY.md](SECURITY.md) rather than a public exploit report.
