# Changelog

## 0.7.0 — Public Alpha

- First public source snapshot of completed stages 1–10.
- Native Windows UI, overlay, durable queue, model routing and model policy.
- Conservative quota/credit submission gates, recovery and explicit security approvals.
- Public installation, architecture, testing, security and contribution documentation.
- Offline Windows CI with dependency and secret checks; no automated release publication.
- Updated cryptography to the audited 50.0.2 line before publication.

Unfinished stage 11 is excluded. Earlier private 1.0/1.0.1 binaries are not this version
and are not redistributed. Public version numbers begin at 0.7.0.
