# Release status

v0.7.0 was the first Public Alpha source distribution. Stage 11–15 are now merged
into main. Release **0.7.1** is being prepared on a separate local branch; no binary
publication has been authorized yet.

See [RU/EN release notes and installation/upgrade instructions](RELEASE_0.7.1.md),
[build instructions](BUILDING.md), [library sources](LIBRARY_SOURCES.md) and
[release checklist](STAGE15.md). Do not upload renamed private installers.

Final artifacts need matching SHA256, complete companion source delivery and owner
publication approval. They are unsigned; SmartScreen may warn or block. Independent
clean consumer Windows testing is unavailable and disclosed, not an automatic release
blocker. Host/isolated-directory and Windows runner QA do not certify that coverage.
