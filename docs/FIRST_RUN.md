# Первый запуск Windows-приложения

Подготовлен кандидат 0.7.1; публикация требует разрешения владельца.
Установка, SHA256, SmartScreen и ограничения: [release notes](RELEASE_0.7.1.md).

1. Установите приложение в папку своего пользователя. Администратор не нужен.
   Codex, его авторизация и Git не входят в установщик; установите их отдельно из
   официальных источников. Mission Control не просит вставлять токен в настройки.
2. Запустите Mission Control. Русский выбран по умолчанию; язык и Dark/Light
   меняются в настройках. В мастере выберите программу Codex и рабочую папку.
   Проверка подключения читает авторизацию, модели и лимиты, без inference.
   Если Codex отсутствует, завершите его установку/авторизацию и повторите проверку.
3. Создайте миссию или проект. Сначала просмотрите пути, команды и зависимости.
   Черновик проекта не предоставляет прав. Подтверждение плана, доступ к папке,
   исполнение конкретного результата и продолжение конкретного turn — разные
   разрешения. Код результата выполняется с вашими правами, не в ОС-песочнице.
4. Запустите очередь только осознанно: inference расходует лимиты аккаунта.
   Проверьте Model Policy, Credit Policy и актуальные лимиты. Неизвестный лимит
   не считается отсутствующим; неизвестный исход операции нельзя повторять вслепую.
5. После прерывания прочитайте checkpoint и предупреждение о возможных уже
   выполненных действиях. Пустой checkpoint не доказывает отсутствие эффектов.
   ACK запроса остановки не доказывает остановку процессов или отмену файловых действий.

## Данные, обновление и удаление

По умолчанию база: `%LOCALAPPDATA%\CodexMissionControl\missions.sqlite3`.
SQLite с защищёнными DPAPI документами привязана к пользователю Windows.
Не копируйте базу в другой аккаунт в расчёте на автоматическое восстановление.
Переносимый экспорт справочный: он не переносит разрешения или исполняемые проекты.

Перед обновлением остановите очередь, дождитесь честного конечного статуса и
сохраните checkpoint. Если исход неизвестен, сначала выполните восстановление.
Закройте приложение. При остановленной программе сохраните всю папку данных
в защищённое место под тем же аккаунтом Windows (включая SQLite sidecar-файлы,
если они остались). Не публикуйте резервную копию. Сверьте SHA256 установщика с
доверенным опубликованным manifest; неподписанная локальная сборка не даёт гарантий
издателя и может вызывать предупреждение SmartScreen.

Повторная установка заменяет файлы программы. Она не очищает очередь, approvals,
checkpoint или проекты. Автоматического обновления нет. Не запускайте старую версию
поверх активного состояния новых этапов: совместимость downgrade не гарантирована.

Удаление через Windows удаляет файлы приложения и ярлыки, сохраняя пользовательские
данные и проекты. Удалять данные вручную стоит только после сохранения нужной истории
и проверки отсутствия незавершённых миссий. При ошибке запуска сообщите версию Windows,
версию приложения и обезличенную ошибку; не прикладывайте токены, базу или приватный код.
